## Arquivos no Repositório

- `aed/01_limpeza_dados_final.ipynb`: Notebook que realiza a limpeza do arquivo `BASE DE DADOS PEDE 2024 - DATATHON.xlsx` e gera o `dados_pede.csv`
- `aed/02_analise_exploratoria.ipynb`: Notebook respondendo as perguntas propostas no projeto, contendo os insights extras no final.
- `aed/03_modelagem_temporal_risco_de_defasagem.ipynb`: Notebook com de modelo de predição que gera os arquivos: `previsoes_risco_2025.csv` e `modelo_risco_nova_defasagem.joblib`
- `requirements.txt`: Arquivo de texto com as bibliotecas necessárias para executar o código.
